# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** through [GitHub's Private Vulnerability Reporting](https://github.com/HansVanEijsden/wordpress-radio-station-rds-extension/security/advisories/new).

Do **not** open a public issue for security problems.

We aim to acknowledge reports within 5 business days and to ship a fix as soon as possible. Thanks for helping to keep this plugin safe.
